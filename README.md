# 💰 Simulador de Comissão

Este projeto é um simulador de comissão baseado em metas de vendas.

## 🚀 Funcionalidades
- Cálculo automático de comissão
- Interface simples e intuitiva
- Aplicação prática baseada em cenário real de vendas

## 💻 Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## 📊 Como funciona
Digite o valor de vendas e o sistema calcula automaticamente a comissão de acordo com a faixa.

## 🎯 Objetivo
Projeto desenvolvido para praticar lógica de programação e criação de interfaces web.
